# apple-stock-performance-analysis

Analysis of Apple’s stock price performance, daily returns, volatility, and trend using Excel, SQL, Python, and Power BI.

## Data Source

[View Apple historical stock data](https://finance.yahoo.com/quote/AAPL/history/)

## Repository Contents

- [Excel analysis workbook](excel/Apple_Stock_Analysis.xlsx): Data preparation, Power Query filtering, KPI calculations, and visualisations.
- [SQL analysis script](sql/apple_analysis.sql): Data validation, daily returns, moving averages, and KPI queries.
- [Python analysis notebook](notebooks/apple_analysis.ipynb): Data cleaning, return and volatility calculations, and chart creation.
- [Power BI dashboard](dashboard/Apple_Stock_Dashboard.pbix): Interactive performance and risk dashboard.
- [Analysis charts](images/): Excel and Python visualisations.
