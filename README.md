# apple-stock-performance-analysis

Analysis of Apple’s stock performance, daily returns, volatility, and price trends using Excel, SQL, Python, and Power BI.

## Repository Contents

- [SQL analysis script](Apple_Analysis.txt): SQL queries for the stock analysis, saved as a text file.
- [Power BI dashboard](Apple_Stock_Dashboard.pbix): Power BI report for exploring stock performance and risk.
- [Python analysis notebook](Apple_analysis.ipynb): Python calculations and visualisations.
- [Excel analysis workbook](Final_Analysis.xlsx.xlsx): Excel analysis, calculations, and charts.
